---

# Working Rules

## Read only what is necessary

DO NOT read the entire project.

Always start from the smallest possible files.

Priority:

1. README.md
2. Docs/
3. Scripts/
4. Requested scene only

Never scan the whole repository unless explicitly asked.

---

## Unity Scene Rules

Never read an entire

- *.unity
- *.prefab
- *.asset

unless explicitly requested.

If a scene is needed:

- search for specific GameObjects
- search for MonoBehaviour names
- inspect only relevant sections
- use git diff when possible

Large Unity YAML files consume excessive context.

---

## Ignore Generated Files

Never inspect or modify:

Library/
Temp/
Logs/
Obj/
Build/
Builds/
UserSettings/
MemoryCaptures/

These folders are generated by Unity.

---

## Code Organization

Gameplay logic lives inside:

Assets/Scripts/

Mission data lives inside:

Assets/GameData/

Scenes should contain references only.

Avoid embedding large datasets inside scenes.

---

## Mission System

Create reusable systems.

Do NOT hardcode missions.

Prefer:

MissionData (ScriptableObject)

instead of large if/else chains.

---

## Git

Never commit:

Library
Temp
Logs
Builds

Respect .gitignore.

---

## Git LFS

Large binary assets should use Git LFS.

Examples:

*.fbx
*.blend
*.wav
*.mp3
*.mp4
*.psd

Do NOT track:

*.cs
*.unity
*.prefab
*.asset
*.meta

with Git LFS.

---

## Coding Style

Prefer:

- small classes
- reusable components
- composition over duplication
- serialized fields instead of magic numbers
- clear variable names

---

## Before Editing

Understand existing architecture.

Make the minimum required change.

Avoid unrelated refactoring.

---

## If Unsure

Ask before making architectural changes.

Never rewrite large scenes automatically.


## Token Optimization

When investigating an issue:

1. Read README first.
2. Read only relevant C# files.
3. Never open large Unity scenes completely.
4. Use targeted search.
5. Prefer git diff over full file reads.
6. Ask before reading any file larger than 500 KB.


Even better: create a project docs folder

Instead of making the AI inspect Unity scenes to understand the project, create:

docs/

    architecture.md

    folder_structure.md

    gameplay.md

    mission_system.md

    scoring.md

    npc_system.md
